MAP 25 NAT & PAT
Core IdeaNAT translates private IPs to public. PAT (overload) maps many:1 using port numbers.
1. NAT Types
  • Static NAT: 1:1 mapping
  • Dynamic NAT: pool of publics
  • PAT/Overload: many:1 (port)
  • Most common: PAT
2. NAT Terminology
  • Inside Local: private src IP
  • Inside Global: translated IP
  • Outside Local: dst as seen inside
  • Outside Global: real dst IP
3. PAT Config
  • ip nat inside source list ACL
  • interface overload
  • ip nat inside on int facing LAN
  • ip nat outside on int facing WAN
4. NAT Limitations
  • Breaks end-to-end reachability
  • Complicates troubleshooting
  • IPsec + NAT needs NAT-T
  • ALG needed for some protocols
⬛ Flow
Host sends packet
→
Inside interface receives
→
NAT translates src IP (+ port for PAT)
→
Forwards to internet
→
Reply translated back
⬛ Terminal
access-list 1 permit 192.168.0.0 0.0.255.255 ip nat inside source list 1 interface GigabitEthernet0/1 overload interface GigabitEthernet0/0 ip nat inside interface GigabitEthernet0/1 ip nat outside show ip nat translations
