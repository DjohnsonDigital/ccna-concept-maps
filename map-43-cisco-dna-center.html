MAP 43 Cisco DNA Center
Core IdeaDNA Center is Cisco's SDN controller for campus/branch. Provides Intent-Based Networking.
1. DNA Center Features
  • Design: network hierarchy
  • Policy: intent-based config
  • Provision: zero-touch deploy
  • Assurance: AI/ML analytics
2. IBN
  • Intent-Based Networking
  • Business intent → network config
  • Continuous verification
  • Self-healing network
3. DNA Center APIs
  • REST API (northbound)
  • HTTPS/JSON
  • Authentication token
  • Postman/Python access
4. SD-Access
  • Overlay on DNA Center
  • VXLAN fabric underlay
  • LISP for control plane
  • Micro-segmentation via SGT
⬛ Flow
Define network intent
→
DNA Center translates to config
→
Pushes config to devices
→
Monitors with assurance
→
Remediates automatically
