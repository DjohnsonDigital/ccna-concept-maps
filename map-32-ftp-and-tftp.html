MAP 32 FTP & TFTP
Core IdeaFTP/TFTP used for IOS image transfers and config backup. TFTP = simple, no auth.
1. TFTP
  • UDP port 69
  • No authentication
  • Simple file transfer
  • Used for IOS upgrades/configs
2. FTP
  • TCP ports 20 (data) 21 (control)
  • Username/password auth
  • Active and passive modes
  • More reliable than TFTP
3. IOS Upgrade via FTP
  • ip ftp username cisco
  • ip ftp password cisco
  • copy ftp: flash:
  • verify /md5 flash:image.bin
4. Config Backup
  • copy running-config tftp:
  • copy startup-config tftp:
  • copy tftp: running-config
  • archive log config
⬛ Flow
Identify source/dest
→
Configure credentials (FTP)
→
Initiate transfer
→
Verify MD5 hash
→
Reload with new image
⬛ Terminal
! Backup config copy running-config tftp://192.168.1.100/R1-config ! IOS upgrade copy ftp://192.168.1.100/c1900-universalk9.bin flash: verify /md5 flash:c1900-universalk9.bin show flash:
