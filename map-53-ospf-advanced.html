MAP 53 OSPF Advanced
Core IdeaOSPF DR/BDR election, LSA types, area types, and OSPF authentication.
1. DR/BDR Deep Dive
  • Only on broadcast (Ethernet)
  • Highest priority wins (then RID)
  • Priority 0 = never DR/BDR
  • Non-preemptive by default
2. OSPF Auth
  • None (default)
  • Clear text: area X auth
  • MD5: area X auth message-digest
  • ip ospf message-digest-key 1 md5 KEY
3. OSPF Network Types
  • Broadcast: Ethernet (DR/BDR)
  • Point-to-Point: Serial (no DR)
  • NBMA: Frame Relay (manual config)
  • Point-to-Multipoint: hub-spoke
4. Route Types
  • O = intra-area OSPF
  • O IA = inter-area (ABR Type 3)
  • O E1/E2 = external (ASBR)
  • O N1/N2 = NSSA external
