MAP 45 Ansible for Network Automation
Core IdeaAnsible is agentless automation using YAML playbooks over SSH. No agents on devices.
1. Ansible Basics
  • Agentless (SSH-based)
  • YAML playbooks
  • Inventory: list of hosts
  • Idempotent execution
2. Key Files
  • inventory: hosts & groups
  • playbook.yml: tasks to run
  • ansible.cfg: config settings
  • roles/: reusable components
3. Playbook Structure
  • hosts: which devices
  • gather_facts: yes/no
  • tasks: list of modules
  • ios_command / ios_config modules
4. Cisco Modules
  • ios_command: run show cmds
  • ios_config: push config lines
  • ios_facts: gather device info
  • napalm: multi-vendor
⬛ Flow
Write inventory
→
Write playbook
→
ansible-playbook run
→
SSH to devices
→
Execute tasks
→
Return results
⬛ Terminal
# inventory.ini [routers] R1 ansible_host=192.168.1.1 # playbook.yml - hosts: routers tasks: - name: Show version ios_command: commands: show version register: output
