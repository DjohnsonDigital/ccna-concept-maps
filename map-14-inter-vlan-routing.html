MAP 14 Inter-VLAN Routing
Core IdeaRouter-on-a-stick or L3 switch SVIs enable routing between VLANs.
1. Router-on-a-Stick
  • One physical link to switch
  • Sub-interfaces per VLAN
  • encapsulation dot1Q
  • ip address on each sub-int
2. SVI (L3 Switch)
  • interface vlan 10
  • ip address on SVI
  • ip routing must be enabled
  • Most efficient for intra-switch
3. L3 Switch Routed
  • no switchport on L3 port
  • Acts like a router port
  • ip routing required
  • ip default-gateway for mgmt
4. Comparison
  • ROAS: cheap, 1 link
  • SVI: fast, no external router
  • L3 routed port: flexible
  • SVI preferred in production
⬛ Flow
VLAN A host
→

→
