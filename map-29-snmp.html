MAP 29 SNMP
Core IdeaSNMP monitors and manages network devices. Agent on device, Manager collects data.
1. SNMP Versions
  • v1: community strings, no encrypt
  • v2c: 64-bit counters, no encrypt
  • v3: auth + encryption (use this!)
  • v3 modes: noAuthNoPriv/AuthNoPriv/AuthPriv
2. Components
  • Manager (NMS): polls/receives
  • Agent: runs on device
  • MIB: database of OIDs
  • OID: specific data object
3. Operations
  • Get: manager requests info
  • Set: manager changes config
  • Trap: unsolicited agent alert
  • Inform: trap + acknowledgment
4. SNMPv3 Config
  • snmp-server group
  • snmp-server user
  • Auth: SHA | Priv: AES
  • snmp-server host
⬛ Flow
SNMP agent enabled
→
NMS polls with Get
→
Agent returns OID data
→
Agent sends Trap on event
→
NMS logs and alerts
⬛ Terminal
snmp-server community PUBLIC ro snmp-server community PRIVATE rw ! SNMPv3 (preferred) snmp-server group MYGROUP v3 priv snmp-server user MYUSER MYGROUP v3 auth sha AUTH123 priv aes 128 PRIV123 show snmp
