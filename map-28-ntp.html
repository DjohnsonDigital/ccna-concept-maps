MAP 28 NTP
Core Idea NTP synchronizes clocks across devices. Accurate time is critical for logs and security.
1. NTP Stratum
  • Stratum 0: atomic clock (ref)
  • Stratum 1: directly connected
  • Stratum 2: syncs to stratum 1
  • Max useful: stratum 15
2. NTP Modes
  • ntp server : client mode
  • ntp master : server mode
  • ntp peer: symmetric
  • ntp broadcast: efficient (LAN)
3. NTP Auth
  • ntp authenticate
  • ntp authentication-key 1 md5 KEY
  • ntp trusted-key 1
  • ntp server 1.1.1.1 key 1
4. Verification
  • show ntp status
  • show ntp associations
  • * = synced peer
  • show clock detail
▶ Flow
Configure NTP server
→
Clients query server
→
NTP exchange packets
→
Clock adjusted
→
Stratum increments by 1
