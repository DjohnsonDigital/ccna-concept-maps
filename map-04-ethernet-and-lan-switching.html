MAP 04 Ethernet & LAN Switching
Core IdeaSwitches learn source MACs and forward/flood based on destination MAC.
1. Ethernet Frame
  • Preamble: 7B sync
  • SFD: 1B start delimiter
  • Dest/Src MAC: 6B each
  • EtherType: 2B | FCS: 4B
2. MAC Address
  • 48-bit / 6-byte
  • First 3B: OUI (vendor)
  • Last 3B: device unique
  • Written: AA:BB:CC:DD:EE:FF
3. Switch Logic
  • Learn: src MAC → port
  • Forward: known dst unicast
  • Flood: unknown/broadcast
  • Age out: default 5 min
4. Duplex & Speed
  • Full duplex: no CSMA/CD
  • Half duplex: CSMA/CD active
  • Speed mismatch = poor perf
  • Duplex mismatch = collisions
