MAP 52 Network Address Translation Deep Dive
Core IdeaPAT (overload) uses both IP and port for many:1 mapping. Inside/outside local/global.
1. NAT Types Review
  • Static: 1:1 (servers/DMZ)
  • Dynamic: pool (less common)
  • PAT/Overload: N:1 (most common)
  • NAT64: IPv6 to IPv4 translation
2. NAT Table Entries
  • Inside Local: client private IP
  • Inside Global: translated public IP
  • Outside Local: dst as seen by inside
  • Outside Global: actual dst IP (same for internet)
3. PAT Port Tracking
  • Same public IP, different ports
  • Translation table: IP+Port
  • Supports 65,535 sessions per IP
  • Scales to thousands of users
4. NAT Troubleshooting
  • show ip nat translations
  • show ip nat statistics
  • debug ip nat
  • clear ip nat translation *
⬛ Flow
Client 192.168.1.10:1024
→
NAT translates: 203.0.113.1:2001
→
Sends to internet
→
Reply to 203.0.113.1:2001
→
NAT maps back to 192.168.1.10:1024
