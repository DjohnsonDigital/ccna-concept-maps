# 📚 CCNA 200-301 Concept Maps

Visual study cards for every CCNA 200-301 exam topic, inspired by [@mapamentalinfo](https://www.instagram.com/mapamentalinfo/) (Alessandro Braga, CCIE).

**Exam Date: January 23, 2027 🎯**

## 🗺️ What's Inside

57 HTML concept maps organized by exam domain. Each map includes:
- **Bold title** with MAP number
- **Core Idea** sticky note — the one sentence that captures the concept
- **4 content columns** — key facts, config, comparisons, gotchas
- **FLOW section** — process walkthrough with arrows
- **TERMINAL section** — essential IOS CLI commands
- **EXAM CHECKLIST** — interactive checkboxes for the most-tested points

## 🚀 How to Use

### Locally
Open `index.html` in any browser — no server needed.

### GitHub Pages
1. Fork or push this repo to GitHub
2. Go to **Settings → Pages → Source: main branch / root**
3. Your maps live at `https://yourusername.github.io/ccna-concept-maps/`

## 📖 Study Tips

- Work through maps in order — each builds on the last
- Use the **EXAM CHECKLIST** checkboxes as you study
- Practice subnetting daily — it's guaranteed on the exam
- Run every CLI command in Packet Tracer or GNS3
- Reference [Jeremy's IT Lab](https://www.youtube.com/c/JeremysITLab) for deep dives
