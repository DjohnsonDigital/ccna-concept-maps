MAP 08 Cisco IOS CLI Basics
Core IdeaIOS has hierarchical modes. Configure → Interface → Exit. Always save config.
1. Exec Modes
  • User EXEC: Router>
  • Privileged EXEC: Router#
  • Global Config: Router(config)#
  • Interface: (config-if)#
2. Navigation
  • enable → privileged EXEC
  • configure terminal → global config
  • interface g0/0 → int config
  • exit / end → step back
3. Essential Commands
  • show version
  • show running-config
  • show interfaces
  • show ip interface brief
4. Saving Config
  • copy running-config startup-config
  • write memory (legacy)
  • show startup-config
  • erase startup-config (reset)
