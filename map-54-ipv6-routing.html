MAP 54 IPv6 Routing
Core IdeaIPv6 uses OSPFv3, EIGRPv6, and static routes. No ARP — uses NDP/ICMPv6.
1. IPv6 Static Routes
  • ipv6 route ::/0 nexthop
  • ipv6 route prefix/len interface
  • Link-local NH needs interface
  • ipv6 unicast-routing required
2. OSPFv3
  • Supports IPv6 (and IPv4)
  • ipv6 router ospf 1
  • ipv6 ospf 1 area 0 on interface
  • Router-ID still 32-bit
3. EIGRPv6
  • ipv6 router eigrp 100
  • eigrp router-id x.x.x.x
  • ipv6 eigrp 100 on interface
  • no shutdown under process
4. IPv6 Address Planning
  • Global: 2000::/3 (routable)
  • Link-local: FE80::/10 (auto)
  • Unique-local: FC00::/7 (private)
  • Loopback: ::1/128
⬛ Flow
Enable ipv6 unicast-routing
→
Assign IPv6 addresses
→
Configure OSPFv3 or static
→
Verify with show ipv6 route
→
Test with ping IPv6
⬛ Terminal
ipv6 unicast-routing interface GigabitEthernet0/0 ipv6 address 2001:db8:1::1/64 ipv6 route ::/0 2001:db8:1::254 router ospf 1 router-id 1.1.1.1 interface GigabitEthernet0/0 ip ospf 1 area 0 show ipv6 route
