MAP 22 OSPF Single-Area
Core IdeaOSPF is a link-state IGP. Forms neighbors, builds LSDB, runs SPF algorithm.
1. OSPF Basics
  • Link-state protocol
  • AD = 110
  • Hello/Dead timers
  • Area 0 = backbone
2. Neighbor States
  • Down → Init → 2-Way
  • → ExStart → Exchange
  • → Loading → Full
  • Full = neighbor relationship
3. DR/BDR Election
  • On multi-access (Ethernet)
  • Highest priority wins (default 1)
  • Highest RID wins tie
  • DR = FULL, others = 2-way
4. Cost Metric
  • Cost = reference-BW / interface-BW
  • Default ref-BW: 100 Mbps
  • auto-cost ref-bandwidth 10000
  • Lower cost = preferred path
