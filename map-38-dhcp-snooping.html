MAP 38 DHCP Snooping
Core IdeaDHCP Snooping prevents rogue DHCP servers. Trusted (uplink) vs untrusted (client) ports.
1. How It Works
  • Switch inspects DHCP messages
  • Trusted ports: DHCP server/uplinks
  • Untrusted ports: client-facing
  • Blocks DHCP Offers from untrusted
2. DHCP Binding Table
  • IP + MAC + port + VLAN
  • Built from DHCP Discover/ACK
  • Used by DAI for validation
  • show ip dhcp snooping binding
3. Config
  • ip dhcp snooping (global)
  • ip dhcp snooping vlan 10
  • ip dhcp snooping trust (on uplink)
  • no ip dhcp snooping limit rate
4. Rate Limiting
  • ip dhcp snooping limit rate 15
  • Per interface (pps limit)
  • Protects against DHCP starvation
  • Applies to untrusted ports
⬛ Flow
Enable DHCP snooping
→
Mark uplink ports trusted
→
Leave client ports untrusted
→
Rogue server blocked
→
Binding table built
⬛ Terminal
ip dhcp snooping ip dhcp snooping vlan 10,20 interface GigabitEthernet0/1 ! uplink to router ip dhcp snooping trust interface range FastEthernet0/1-24 ! client ports ip dhcp snooping limit rate 15 show ip dhcp snooping binding
