MAP 47 JSON & YAML
Core IdeaJSON is API data format. YAML is human-readable config format. Know both for automation.
1. JSON
  • JavaScript Object Notation
  • Key-value pairs: {"key": "val"}
  • Arrays: ["a", "b", "c"]
  • Nested: objects within objects
2. JSON Data Types
  • String: "text"
  • Number: 42 or 3.14
  • Boolean: true/false
  • null: no value | Array: []
3. YAML
  • YAML Ain't Markup Language
  • Human-readable
  • Indentation-based (no braces)
  • Used in Ansible, K8s, Docker
4. YAML vs JSON
  • YAML: spaces not tabs
  • key: value (no quotes needed)
  • List: - item (dash prefix)
  • # comments allowed in YAML
⬛ Flow
API returns JSON
→
Parse with json.loads()
→
Access with dict['key']
→
YAML read for config
→
Convert: yaml.safe_load()
⬛ Terminal
# JSON example {"hostname": "R1", "interfaces": [{"name": "Gi0/0", "ip": "10.0.0.1"}]} # YAML equivalent hostname: R1 interfaces: - name: Gi0/0 ip: 10.0.0.1
