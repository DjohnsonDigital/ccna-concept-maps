MAP 44 REST APIs
Core IdeaREST APIs use HTTP methods (GET/POST/PUT/DELETE) to interact with network controllers.
1. REST Basics
  • Representational State Transfer
  • Stateless: each req independent
  • HTTP/HTTPS protocol
  • JSON or XML data format
2. HTTP Methods
  • GET: retrieve data (read)
  • POST: create new resource
  • PUT: replace/update resource
  • DELETE: remove resource
3. HTTP Status Codes
  • 200 OK: success
  • 201 Created: resource made
  • 400 Bad Request: invalid
  • 401 Unauthorized: auth needed
  • 404 Not Found | 500 Server Error
4. Authentication
  • Basic auth: base64 user:pass
  • Token-based: X-Auth-Token
  • OAuth 2.0: modern standard
  • API key in header
⬛ Flow
Client sends HTTP request
→
Include auth header
→
Controller processes
→
Returns JSON/XML response
→
Client parses response
