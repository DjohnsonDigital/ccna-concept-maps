MAP 35 Port Security
Core Idea Port security limits MACs per port and protects against MAC flooding attacks.
1. Port Security Basics
  • Limits MAC addresses per port
  • Configured on access ports only
  • Violation actions: protect/restrict/shutdown
  • Default: shutdown (most secure)
2. MAC Learning
  • Static: manually configured
  • Dynamic: learned (not saved)
  • Sticky: learned + saved to config
  • Sticky = persistent dynamic
3. Violation Modes
  • Shutdown: port disabled (default)
  • Restrict: drop + increment counter
  • Protect: drop, no counter
  • Shutdown = most secure
4. Recovery
  • errdisable recovery cause psecure
  • errdisable recovery interval 300
  • Manual: shut → no shut
  • show port-security interface
