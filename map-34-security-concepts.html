MAP 34 Security Concepts
Core IdeaCIA Triad: Confidentiality, Integrity, Availability. Understand threats and mitigations.
1. CIA Triad
  • Confidentiality: only authorized access
  • Integrity: data not tampered
  • Availability: services accessible
  • All three must be maintained
2. Common Threats
  • DoS/DDoS: flood attack
  • Man-in-the-Middle: intercept
  • Phishing: credential theft
  • Reconnaissance: info gathering
3. Attack Types
  • Password attacks: brute force
  • Malware: virus/worm/ransomware
  • Spoofing: fake identity
  • Insider threat: trusted user
4. Defense Layers
  • Perimeter: firewall/IPS
  • Network: ACLs/segmentation
  • Host: endpoint protection
  • Data: encryption
