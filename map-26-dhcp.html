MAP 26 DHCP
Core IdeaDHCP dynamically assigns IP, mask, gateway, DNS. Uses DORA process.
1. DORA Process
  • Discover: broadcast from client
  • Offer: server proposes IP
  • Request: client accepts offer
  • Acknowledge: server confirms
2. DHCP Server Config
  • ip dhcp pool NAME
  • network x.x.x.x /mask
  • default-router (gateway)
  • dns-server (DNS IP)
3. DHCP Relay
  • ip helper-address
  • On router interface facing clients
  • Converts broadcast to unicast
  • Forward to DHCP server
4. DHCP Snooping
  • Switch security feature
  • Trusted vs untrusted ports
  • Blocks rogue DHCP servers
  • Required for DAI
⬛ Flow
Client boots
→
Broadcasts Discover
→
Server sends Offer
→
Client sends Request
→
Server sends ACK
→
Client configures IP
