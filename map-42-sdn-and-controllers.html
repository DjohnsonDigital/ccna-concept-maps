MAP 42 SDN & Controllers
Core IdeaSDN separates control plane from data plane. Controller centralizes intelligence.
1. Traditional Networking
  • Control plane: on each device
  • Data plane: on each device
  • Distributed decision making
  • CLI management per device
2. SDN Architecture
  • Control plane: centralized controller
  • Data plane: stays on device
  • Northbound API: apps to controller
  • Southbound API: controller to devices
3. Planes
  • Management plane: device mgmt
  • Control plane: routing decisions
  • Data plane: packet forwarding
  • SDN centralizes control plane
4. Cisco SDN Products
  • Cisco DNA Center (campus)
  • ACI: data center SDN
  • SD-WAN: Viptela/meraki
  • NSO: network service orchestrator
