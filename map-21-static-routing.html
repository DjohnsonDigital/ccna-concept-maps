MAP 21 Static Routing
Core IdeaStatic routes are manually configured. Used for small networks or specific paths.
1. Static Route Types
  • Standard: ip route dst mask nexthop
  • Default: ip route 0.0.0.0 0.0.0.0
  • Summary: aggregates subnets
  • Floating: higher AD for backup
2. Next-Hop Options
  • Next-hop IP address
  • Exit interface (use with P2P)
  • Both: IP + interface
  • Recursive lookup if IP only
3. Floating Static
  • Higher AD than dynamic route
  • Only used if primary fails
  • ip route ... 200 (AD override)
  • Backup path/failover
4. IPv6 Static
  • ipv6 route prefix/len nexthop
  • ipv6 route ::/0 nexthop (default)
  • Link-local NH needs interface
  • ipv6 unicast-routing required
⬛ Flow
Identify destination
→
Determine next-hop
→
Enter ip route command
→
Verify in routing table
→
Test with ping/traceroute
