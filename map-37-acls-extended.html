MAP 37 ACLs — Extended
Core IdeaExtended ACLs filter by src/dst IP, protocol, port. Applied close to source.
1. Extended ACL
  • Matches: src IP, dst IP, protocol, port
  • Numbered: 100-199 and 2000-2699
  • Apply close to SOURCE
  • More granular than standard
2. Protocol Matching
  • ip: matches all IP
  • tcp: TCP traffic
  • udp: UDP traffic
  • icmp: ping/traceroute
3. Port Matching
  • eq: equal to (=)
  • gt/lt: greater/less than
  • range: port range
  • neq: not equal
4. Established
  • TCP established keyword
  • Matches reply traffic (ACK/RST)
  • Allows return traffic inbound
  • Used in stateless firewalls
⬛ Flow
Define source/dest
→
Specify protocol
→
Specify port (eq/gt/lt)
→
Apply near source
→
Verify and test
